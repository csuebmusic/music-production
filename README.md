# music-production

Handouts and browser-based tools for the music producers Inés Thiebaut works with in private lessons, independent of any single course: beat-making, mixing, arrangement, DAW production, and the craft questions that come up across projects. Material can start from the MUS 381 handouts ([`csuebmusic/mus381`](https://github.com/csuebmusic/mus381)), adapted one step deeper and without the course scaffolding (lab session routines, the class server workflow, TA teaching notes).

The landing page, [csuebmusic.github.io/music-production](https://csuebmusic.github.io/music-production/), is built from `index.html` and links every page.

## conventions

The rules in [`mus381/under-the-hood/meta/build-conventions.md`](https://github.com/csuebmusic/mus381/blob/main/under-the-hood/meta/build-conventions.md) apply here, except for file naming, page chrome, the palette, and the audio standard, which are this repo's own.

Pages are topic-named files in topic folders, without course numbers or type prefixes: `foundations/digital-audio.html`. Media for a topic is in `assets/audio/<topic>/`, `assets/images/<topic>/`, and `assets/videos/<topic>/`. Page chrome and the palette are defined in this repo's `assets/style.css`. The audio standard is stated on the pages.
